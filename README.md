# Casa Aleluya - Proyecto Web Informativo

Este proyecto es una página web dedicada a **Casa Aleluya**, un reconocido hogar y centro de atención integral ubicado en Guatemala. Esta institución se dedica a brindar refugio, educación, cuidado médico y apoyo a niños, niñas y jóvenes que han enfrentado situaciones de vulnerabilidad, abandono o abuso.

**Propósito del sitio:**
Esta página web fue desarrollada con un fin única y estrictamente **informativo**. Su objetivo principal es dar a conocer el lugar, compartir la misión de Casa Aleluya y visibilizar la labor vital que realizan día a día. Sirve como una ventana digital para que cualquier persona interesada pueda informarse sobre sus instalaciones y el impacto positivo que generan en la comunidad.

## 📖 Manual Técnico

Su propósito es proveer a otros desarrolladores toda la información necesaria sobre la arquitectura del software, las dependencias tecnológicas y los pasos exactos para configurar, compilar y desplegar el entorno de desarrollo de manera local.

##  Tecnologías Utilizadas

Este proyecto fue construido utilizando las siguientes herramientas modernas de desarrollo:

*   **Next.js:** Framework de React para el renderizado y enrutamiento.
*   **React:** Librería para la construcción de interfaces de usuario.
*   **TypeScript:** Superconjunto de JavaScript que añade tipado estático.
*   **Tailwind CSS:** Framework de CSS para un diseño rápido y responsivo.

##  Requisitos Previos

Para ejecutar este proyecto en tu entorno local, asegúrate de tener instalado lo siguiente:

*   [Node.js](https://nodejs.org/) (Se recomienda la versión LTS)

## Instalación y Ejecución Local

Sigue estos pasos para tener una copia funcional del proyecto en tu computadora:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/ferzincal/ProyectoDesarrolloWeb](https://github.com/ferzincal/ProyectoDesarrolloWeb)
**2. Acceder a la carpeta del proyecto**
Una vez descargado, debes moverte hacia el directorio que se acaba de crear para poder interactuar con los archivos:
```bash
cd ProyectoDesarrolloWeb
```

**3. Instalar las dependencias**
Este proyecto utiliza diversas librerías y herramientas externas. Para que Node.js las descargue y configure automáticamente, ejecuta:
```bash
npm install
```
>  **Nota:** Este proceso puede tardar un par de minutos. Es completamente normal si en la consola aparecen advertencias (textos en amarillo) sobre versiones de paquetes. 

**4. Levantar el servidor de desarrollo**
Cuando la instalación termine, ya estarás listo para encender el entorno de prueba local:
```bash
npm run dev
```

**5. Visualizar la página web**
¡Todo listo! La terminal te indicará que el servidor está corriendo. Abre tu navegador web de preferencia (Chrome, Edge, Firefox, etc.) y visita la siguiente dirección:
 **[http://localhost:3000](http://localhost:3000)**
